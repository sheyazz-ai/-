# SystemMonitor

Один exe, без установки: `dist\SystemMonitor.exe` (около 48 МБ, .NET внутри). Запуск от администратора — UAC спросит сам.

## Что показывает

Верхние карточки: загрузка CPU, занятая память, температура CPU/GPU, разрешение и герцовка монитора, число запущенных приложений и сколько из них тяжёлых. Ниже — два графика за последние 2 минуты (CPU и заполнение ОЗУ).

Графики растягиваются на всю ширину сразу, с первых секунд работы, имеют шкалу 0–100 % и не сбрасываются при смене интерфейса. Раньше линия занимала несколько пикселей у правого края, пока не наберётся 120 точек, — это исправлено.

Таблица — только пользовательские программы: процессы сессии 0 (службы Windows) и всё, что запущено из `C:\Windows`, отфильтровано. Колонки: имя, PID, CPU %, RAM в МБ, время запуска, полный путь. Тяжёлые помечены красной точкой и подсвечены: CPU ≥ 10 % или RAM ≥ 500 МБ.

## Выбор интерфейса

В верхней строке окна есть меню **«Интерфейс»**:

- **Тема оформления** — «Графит» (тёмная, по умолчанию), «Светлая», «Полночь», «Контраст». Применяется сразу, включая заголовок окна, меню и графики.
- **Плотность** — «Компактная», «Обычная», «Просторная»: размеры карточек, графиков и строк таблицы.
- **Состав экрана** — «Полный» (карточки + графики + список), «Без графиков», «Только список», «Дашборд» (только карточки и большие графики).
- **Сбросить оформление** — возвращает «Графит · Обычная · Полный».

Выбор запоминается в `%APPDATA%\SystemMonitor\ui.json` и восстанавливается при следующем запуске. Текущий вариант показан справа в верхней строке.

Горячие клавиши и подсказки — в меню **«Справка»**.

## Управление

- Клик по заголовку колонки — сортировка (повторный клик меняет направление, стрелка показывает текущее).
- `Delete` — завершить выбранные процессы (можно несколько через Ctrl/Shift).
- Правый клик — завершить процесс, завершить дерево процессов, открыть папку с файлом, скопировать путь, свойства файла.
- Двойной клик — открыть папку с файлом.
- `F5` — обновить принудительно.
- Поиск — по имени процесса или по пути; чекбокс «Только тяжёлые» оставляет только тяжёлые.

Порог «тяжёлого» задан константами `HeavyCpu` и `HeavyRam` в начале `SystemMonitor\MainForm.cs`.

## Температура

Читается через LibreHardwareMonitor: CPU Package/Core Max и GPU Core. Требует прав администратора. Если стоит включённая изоляция ядра (HVCI / Core Isolation) или драйвер датчиков блокируется антивирусом, вместо значений будет «н/д» — остальной мониторинг работает.

## Пересборка

```
build.cmd
```

Нужен .NET SDK 10; результат кладётся в `dist\`. Можно запускать исходники без публикации: `dotnet run --project SystemMonitor` (появится запрос UAC из-за манифеста).

## Исходники

- `SystemMonitor\MainForm.cs` — интерфейс, таблица, меню выбора темы/плотности/состава.
- `SystemMonitor\UiTheme.cs` — палитры тем, плотности, варианты раскладки и сохранение настроек.
- `SystemMonitor\UiMenuRenderer.cs` — отрисовка меню в цветах темы.
- `SystemMonitor\Sparkline.cs` — графики.
- `SystemMonitor\ProcessSampler.cs` — сбор CPU/RAM/путей через WinAPI.
- `SystemMonitor\HardwareMonitor.cs` — датчики и режим экрана.
- `SystemMonitor\Native.cs` — P/Invoke.
- `SystemMonitor\app.manifest` — запрос прав администратора.

`preview.png` — снимок интерфейса в тёмной теме. Примеры всех тем, плотностей и раскладок, а также открытое меню «Интерфейс» — в папке `screenshots\`.
